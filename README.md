Versió catalana
  guaita_pdf_edit_5.0.html          Mode pestanya: doble clic i s'obre al navegador.
  guaita_pdf_edit_5.0_app.html      Mode aplicació (amb avís en tancar si hi ha documents oberts).
  Obrir_Guaita_PDF_Edit_app.bat     Windows: obre el *_app.html català en finestra d'aplicació (Edge, Chrome o Brave).

English version
  guaita_pdf_edit_5.0_EN.html, guaita_pdf_edit_5.0_EN_app.html,
  Open_Guaita_PDF_Edit_app_EN.bat / .command, guaitaPDFscan_1.1_EN.html

Deixa tots els fitxers a la mateixa carpeta: l'editor obre l'analitzador des d'aquesta carpeta
i el navegador ha de permetre les finestres emergents per a la pàgina.

Novetats 5.0
  · Fitxer › Exportar a DXF… (integrat a l'editor; DXF R12 per capes de color, amb escala i calibratge).
  · Fitxer › Analitzar PDF sospitós… (guaitaPDFscan 1.1; el PDF net torna a l'editor com a document nou).
  · Menú Ajuda: guia d'ús, dreceres de teclat i Quant a.
  · Versió anglesa.
  · Correcció: les pàgines amb rotació pròpia (/Rotate) ara es mostren i es desen amb la seva orientació.
