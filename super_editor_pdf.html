Guaita PDF Edit 5.0

Multi-document PDF editor in a single HTML file. It installs nothing, connects to no server and works offline: your PDFs never leave your computer. It includes original-content editing, bookmarks, DXF export and the suspicious-PDF analyser guaitaPDFscan.

01

What it is
Local and private
Everything runs in the browser. No CDN, no server.
Multi-document
Each PDF gets its own tab; copy pages between documents.
Real editing
Original text and images, annotations, bookmarks and signature.
Security and CAD
Export to DXF and disarm suspicious PDFs with guaitaPDFscan.

Components: pdf.js 3.11.174 (Mozilla, Apache-2.0), pdf-lib 1.17.1 and @pdf-lib/fontkit 1.1.1 (MIT), all embedded.

02

Open, save and print
  1. File › Open or drop one or more PDFs on the window.
  2. Edit (pages, annotations, content, bookmarks).
  3. Save current PDF generates a new PDF with all changes.

Print shows a preview comparing the paper size with the PDF's and lets you choose paper (A4, A3…), orientation and scale, with zoom in the preview. Merge all creates a document with every tab.

03

Pages and view

The thumbnails on the left let you select (Ctrl+click), reorder by dragging, rotate, duplicate, extract, delete and insert blank pages or pages from another PDF. Change the thumbnail size by dragging the column edge or with Ctrl+wheel.

Views: single page (for editing), two-page book with page turning, continuous and continuous in two columns. Pages with their own /Rotate are displayed and saved correctly rotated.

04

Annotations

Pencil, highlighter, text, shapes, signature, images, watermark and page numbers. With Select (V) you move, scale and rotate objects and change their order or opacity. The Measure tool (M) gives distances at the chosen scale (1:).

05

Edit the original content

With the ✎ Content tool (X), click a text in the PDF to change it.

ModeWhat it does
OriginalEdits using the letters of the original embedded font.
CombineKeeps the original letters and fills in only the missing ones with the replacement font (standard, .ttf/.otf file or installed font).
Rewrite whole fragmentThe whole fragment in the replacement font (uniform look).
OverlayCovers the original with the background colour and writes on top (the original stays underneath).

Click an image in the PDF to delete it, replace it or turn it into a movable object.

If the original content differs from the analysis, the edit is skipped with a warning instead of corrupting the PDF.

06

Bookmarks

The 🔖 Bookmarks tab shows the PDF's bookmark tree: read, create, edit and navigate.

  • Ctrl+B adds a bookmark to the current page.
  • Double-click or F2 to rename; drag to reorder or nest.
  • Change colour, bold, italic and open/closed state.
  • Alt+↑/↓ jumps to the previous or next bookmark.

They are saved inside the PDF (/Outlines) and followed when extracting, duplicating and merging pages.

Navigation goes to the page, not to the exact destination position. “Insert from PDF” does not import bookmarks.

07

Export to DXF

File › Export to DXF… converts the vector geometry of the current page, the selected pages or all pages into R12 (AC1009) DXF files, the most compatible format.

OptionDetail
ContentLines, polylines (curves are split into segments) and texts.
LayersOne layer per colour (COL_rrggbb) with the nearest ACI.
UnitsMillimetres or points.
ScaleThe same as the Measure tool's; can be calibrated with the last measurement.
QualityCurve smoothness and a filter for tiny segments.
IncludesContent edits and, optionally, annotations. Page rotation is respected.
Images and shadings are not exported. Text is encoded in Windows-1252.

08

Analyse a suspicious PDF (guaitaPDFscan)

File › Analyse suspicious PDF… opens guaitaPDFscan in a separate window. The suspicious PDF is opened and analysed only in the analyser, never in the editor.

  1. Load the suspicious PDF in guaitaPDFscan and analyse it.
  2. Disarm and save it.
  3. Press Open in guaitaPDF Edit: the editor receives the clean PDF and opens it as a new document.

Connection security

Communication uses postMessage with a versioned protocol. The editor only accepts messages from the window it opened, with app guaitaPDFscan, an ArrayBuffer of 1 B to 500 MB starting with %PDF- and a sanitised name (no \ / : * ? " < > |).

The file guaitaPDFscan_1.1_EN.html must be in the same folder as the editor and the browser must allow pop-ups.

09

Tab mode and app mode

The *_app.html file is the same program prepared to open as an app (no address bar) with the launchers Open_Guaita_PDF_Edit_app_EN.bat (Windows) or .command (macOS/Linux).

FAQ
Why doesn't the analyser open?Check that guaitaPDFscan_1.1_EN.html is in the same folder and that the browser is not blocking pop-ups.
Can I publish them on GitHub Pages?Yes: they are static files. Serve them over HTTPS and keep the editor and analyser in the same directory.
The DXF has no imagesKnown limitation: only vector geometry and text are exported.
